Bien démarrer

      
Authentification

      
Chaque appel transmet la clé dans l'en-tête X-API-Key. Les applications serveur peuvent aussi utiliser un jeton OAuth2 (flux client credentials) délivré par le serveur d'identité.

      
Formats

      
Les réponses sont en JSON. Les objets géographiques suivent GeoJSON (RFC 7946) en WGS 84 (EPSG:4326). Le paramètre crs=32628 renvoie les coordonnées en UTM zone 28N, système de référence courant au Sénégal.

      
Codes d'erreur

      
CodeSignification

        
400Paramètre manquant ou mal formé. Le message précise lequel.

        
401Clé absente ou invalide.

        
403Clé valide mais API non incluse dans votre offre.

        
429Quota dépassé. L'en-tête Retry-After indique le délai.

        
503Service en maintenance. Consultez la page d'état.
